# Metro Medical Center — Healthcare System Manual & Clinical Policies

## 1. Emergency Hospital Codes & Responses
- **Code 99 (Adult Cardiac Arrest)**: Call **x7-7777**. STAT response: Code Blue Team, Pharmacist with Code Cart.
- **Trauma STAT (Level 1 Trauma Alert)**: Overhead announcement to Trauma Bay Alpha/Beta. Blood bank prepares Trauma Pack 1 instantly.
- **Code Yellow (External Disaster)**: Emergency department surge protocol initiated.

## 2. Hospital Departmental Directory
- **Transfusion Medicine (Blood Bank)**: **x7-2200** (Direct line to Transfusion Supervisor).
- **Inpatient Pharmacy Satellite**: **x7-3400**.
- **Central Sterile Processing Department (SPD)**: **x7-1150**.
- **Security & Workplace Safety**: **x7-9999**.
- **Administrative House Manager**: **x7-0010**.

## 3. Clinical Governance Policies
- Universal double check on all parenteral high-alert medications (Insulin, Heparin, PCA opioids, Chemotherapy).
- Hand Hygiene Compliance: Clean In / Clean Out for every patient encounter.
